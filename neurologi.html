  • Demens — smygande, kronisk kognitiv svikt. Se Äldre — delirium & BPSD (Akut psykofarmaka) →
  • Wernicke–Korsakoff — Wernicke (akut tiaminbrist: konfusion, oftalmoplegi, ataxi) → obehandlad ger Korsakoffs syndrom (kronisk anterograd amnesi med konfabulation). Se Wernicke-behandling (Beroende) →
  • Neurosyfilis — psykiatrisk bild / progredierande kognitiv svikt. Se Infektion →
  • Herpesencefalit — feber, snabb progress, fokalneurologi/kramper. Se Infektion →

Yrsel, synkope & skallskada

Synkope

Plötslig, självlimiterande medvetandeförlust pga global transitorisk cerebral hypoperfusion. Tre grupper: reflex (vasovagal/situationell/karotissinus) 50–60 %, ortostatisk 10–30 %, kardiell 10–15 %. Psykogen pseudosynkope kan imitera.

  • Utredning: hjärt-/lungstatus, EKG (alltid), BT liggande + stående (1–3 min), SpO₂; lab (Hb, elektrolyter, glukos, TnT, ev. NT-proBNP). DT skalle tillför inget utan neurologisk misstanke.
  • Högrisk: synkope i liggande/under ansträngning, plötslig hjärtklappning innan, strukturell hjärtsjukdom, patologiskt EKG (AV-block II typ II / III, VT, lång/kort QT, Brugada, skänkelblock), samtidig bröst-/buksmärta eller dyspné, hög ålder, trauma utan förkänning.
  • Vårdnivå: högrisk → telemetri 6–24 h (AVA/MAVA) + kardiologkontakt (kardiell genes = hög mortalitet). Reflex/ortostatisk hos yngre (< 60 år) → poliklinisk utredning.

Yrsel

Fokusera akut på att utesluta farligt: stroke (särskilt bakre skallgrop), infektion, arytmi.

  • Anamnes: timing/debut, förlopp (konstant/episodisk/fluktuerande), triggers, andra symtom (bortfall, hörselnedsättning). Yrselns karaktär (rotatorisk vs gungande) är sällan värdeskapande.
  • Status: ABCDE, EKG, cor/pulm, neurologstatus på alla (inkl. hörsel), otoskopi. Obs skew och nystagmus.
  • Central genes (misstänk stroke): riktningsväxlande/vertikal nystagmus, normalt head impulse-test, skew, nya bortfall. DT är ej känsligt för stroke i bakre skallgropen → vid statusfynd, inläggning + MR (rådgör neurolog).
  • BPPV: Dix-Hallpike / supine roll → repositionsmanöver.

Källa: Akut Internmedicin (SUS). Verifiera mot lokal rutin.

Skallskada — DT-beslut

CT Head Rule ↗

Beslutsstöd för DT-skalle vid huvudtrauma. Validerad ≥ 16 år; gäller inte vid antikoagulantia, koagulationsrubbning eller kramp efter traumat.

Högrisk — sänk tröskeln för DT:
  • Antikoagulantia / trombocythämmare — DT även vid lindrigt trauma, observera (fördröjd blödning).
  • Alkohol / intoxikation — försvårar GCS-bedömningen.
  • Äldre och lågt fall — högre blödningsrisk även vid lindrigt trauma.

Varningstecken

Tilltagande huvudvärk, upprepade kräkningar, sjunkande medvetande, fokalneurologi, kramp.

Subtila tecken — misstänk basal skallfraktur

Hos en i övrigt opåverkad patient med känt skalltrauma, leta efter:

  • Brillhematom (raccoon eyes) — bilaterala periorbitala hematom.
  • Battles tecken — hematom över mastoiden (bakom örat).
  • Likvorré — läckage av likvor (CSF) från örat (oto-) eller näsan (rino-).
  • Hemotympanum — blod bakom trumhinnan.

S100B (hjärnskademarkör)

  • Används i skandinaviska riktlinjer vid lätt skallskada (GCS 14–15) för att undvika onödig DT.
  • Ta inom 6 h efter trauma (peak 1–2 h, kort halveringstid).
  • < 0,10 µg/L → låg risk, DT kan avstås (högt negativt prediktivt värde).
  • Gäller endast lågriskpatienter; falskt förhöjt vid extrakraniella skador (frakturer/mjukdelsskada) — då ej användbart.

Verifiera mot lokal rutin.

Annat

Normaltryckshydrocefalus (NPH)

Behandlingsbar orsak till kognitiv svikt. Klassisk triad: gångstörning, kognitiv svikt (subkortikal förlångsamning) och urininkontinens — gångstörningen debuterar oftast först.

  • Utredning: DT/MR — ventrikelvidgning oproportionerlig mot atrofi (Evans index > 0,3).
  • Konsultera neurolog för ställningstagande till CSF-tapptest (LP med tömning ~30–50 ml likvor) → förbättrad gång talar för shuntnytta.
  • Vidare behandling via neurokirurgi med ventrikuloperitoneal (VP) shunt. Gångstörningen svarar bäst.

Funikulär myelos

Funktionell B12-brist (bl.a. vid lustgas). Parestesier, gångataxi, nedsatt vibrations-/positionssinne. Se Lustgas (Beroende) →

Osmotiskt demyeliniserande syndrom (ODS / central pontin myelinolys)

Vid för snabb korrigering av hyponatremi; ökad risk vid alkohol/malnutrition. Se hyponatremi-behandling (Internmedicin) →

Charles Bonnet-syndrom

Komplexa visuella hallucinationer hos personer med nedsatt syn (t.ex. makuladegeneration, glaukom), med bibehållen insikt och utan andra psykotiska symtom. Benignt — viktigt att känna igen så det inte feltolkas som psykos. Handläggning: förklaring/lugnande besked, optimera synen; antipsykotika behövs i regel inte.
